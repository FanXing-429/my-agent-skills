# my-agent-skills

Personal Codex/agent skills.

## Skills

- `macbook-server-setup`: Configure a MacBook to behave like a low-power macOS server, including sleep prevention, VNC/SSH diagnostics, and recovery guidance.

## Install

Copy a skill directory into your Codex skills folder:

```bash
cp -R skills/macbook-server-setup ~/.codex/skills/
```

Restart Codex or start a new session so the skill metadata is discovered.
